# SendPulse MCP — моушн-интро (16:9, без голоса и звука)

Четыре слайда (`assets/src/scr_1..4.webp`) анимированы в один ролик 1920×1080, 60 fps, 31 с.
В конце всё уходит и остаётся чистый фон для скринкастов.

| время | что происходит |
|---|---|
| 0.0 – 6.0 | **Слайд 1** (`scr_1`): логотип поднимается из маски, пульс прорисовывается слева направо, заголовок появляется по словам (бирюзовая строка последней), четыре карточки категорий всплывают по очереди, снизу выезжает плашка рейтингов. Медленный наезд камеры. |
| 5.6 – 13.2 | **Слайд 2** (`scr_4`): прорисовываются орбиты, плашка «SendPulse MCP» появляется с отскоком, иконки сервисов влетают по своим эллиптическим орбитам и вращаются вокруг неё как планеты (внутренние быстрее); от центра расходятся три волны. На выходе иконки улетают по орбитам, орбиты раскрываются и остаются тонкими линиями фона. |
| 12.9 – 19.3 | **Слайд 3** (`scr_3`): сверху свечение и точечная сетка; плашки Email / Chatbot / Automation падают сверху с лёгким отскоком; карточки интерфейса всплывают снизу (сначала средняя) и слегка покачиваются. |
| 18.85 – 25.2 | **Слайд 4** (`scr_2`): то же для Pop-ups / Landing page / CRM. |
| 25.2 – 31.0 | **Чистый фон**: свечение, точки и две тонкие линии, без текста. Свечение очень медленно «дышит». |

## Как это сделано
- `tools/extract.py` вырезает из слайдов прозрачные слои (`assets/cut/*.png`, координаты в `film/cut.js`).
  Фон всех слайдов — один сплошной цвет `#023347`, поэтому текст отделяется от фона без потерь, а карточки и
  иконки режутся по их скруглённым границам. `tools/recompose.py` собирает слои обратно и сравнивает с оригиналом
  (средняя разница < 1 уровня из 255).
- `film/film.js` — вся анимация (пружины движка motion-film; время в секундах, `bpm 60`).
- Фон (свечение, точки, орбиты) рисуется в коде, а не берётся из слайдов, поэтому финальная подложка чистая.

## Команды (из этой папки)
```
.venv/bin/python tools/extract.py      # пересобрать слои из assets/src
node scripts/render.mjs --sheet        # раскадровка → review/sheets/
node scripts/render.mjs                # финал → renders/16x9.mp4
node scripts/render.mjs --at 28        # кадр чистого фона → review/stills/16x9/t28.000.png
```
Тайминги меняются в `film/film.js` (начала слайдов: `T2`, `OUT1`, `OUT2`, аргументы `productSlide(...)`),
длительность — `duration` в `timeline.json`.
